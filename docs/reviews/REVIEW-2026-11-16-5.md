## Summary

**All of review 4 is fixed.** M1, M2 and L1–L10 are all fixed. The fixes are well tested (`backend/tests/review4.rs`, `packages/ui/src/__tests__/review4.test.tsx`). Two loose ends from the L1/L2 fixes are below the bar for a medium (new L5 and L9).

**The fan-out worker is correct.**
- Each chunk runs in one `BEGIN IMMEDIATE` transaction, and that transaction also advances or removes the cursor. A restart therefore resumes with no duplicates and no gaps.
- A follower who unfollows mid-run is skipped. Follows created after the publish are excluded by `created_at <= published_at`.
- A deleted game cascades its queue row away, and the chunk then sees `None`.
- An unpublish mid-run only writes rows that the read-time visibility filter already hides.
- I replayed the chunk SQL on a seeded database: 1,209 followers, one unfollow mid-run and one deleted follower gave 1,207 rows for 1,207 distinct recipients.

**Migration 0014 applies cleanly to a 0013 database.** It removes the event-less rows, the new trigger fires on FK cascades, and `foreign_key_check` and `integrity_check` are clean.

**F012 is well built and well tested, with three gaps:**
1. **Synthetic releases fire buttons (new M2).** A pointer "release" that the user never made activates an `engine.ui` button. Window blur, the engine's pause and `pointercancel` all call `releaseAll()`. So a player holding the mouse on "QUIT" who alt-tabs, or whose game is auto-paused, triggers it on resume.
2. **The text `.fnt` parser is quadratic (L1).** The attribute regex backtracks over long runs of word characters, which defeats the 1 MiB "hard limit". The cost stays inside the game's own sandbox, so this is low.
3. **A doc claim is false (L2).** ARCHITECTURE.md says page paths "can't leave the bundle", but a double-encoded `%252e%252e` does leave it.

**The biggest performance problem predates this round (new M1).** The server sends every response uncompressed: there's no compression middleware. That applies to the SPA bundle (608 KB → 181 KB gzip), its 2.4 MB source map and `engine.js` (131 KB → 41 KB). The engine grew by about 22 KB minified (about 8 KB gzip) this round. I found little to trim from that: the modules are already compact, and the long error strings are worth roughly 1–2 KB. Compression saves about 10× more than any trimming would.

## Checked and fine

- **BMFont limits.**
  - Pages are 1–16 and chars 1–8192, both enforced *while* the text format is read. Kernings are capped at 65536.
  - Every numeric field is range-checked and rounded. `packed` is rejected and XML is rejected.
  - The JSON path rejects non-objects. `__proto__` keys are inert: an assignment to `__proto__` with a string is ignored, and JSON.parse keeps it as an own key that is never read.
  - Glyphs outside their page are dropped with a warning. The kerning key `first·0x110000+second` stays below 2^53.
  - Page names reject schemes, leading `/` or `\`, and non-image extensions. (The double-encoding gap is L2.)
- **Studio, backend and desktop `.fnt` allowlists** agree across `bundle.rs`, `files.rs` (`text/plain; charset=utf-8`), `project.ts`, desktop `project.rs`, `files.ts`, the vite dev map and `pack-examples.mjs`. `tests/f012.rs` covers upload, replace, MIME and headers, and the desktop test covers text reading.
- **`engine.ui` input.**
  - Tab is never used, and Escape and gamepad B clear focus. Navigation reads declared F009 actions through `input.actions` before `actionPressed`, so remaps apply and no unknown-id warnings fire.
  - `nav: false` keeps HUD buttons out of the order. Focus, active and hot are cleared at the end of a step for undeclared or disabled ids.
  - On touch, a tap with press and release in one step fires once, and `pointerleave` after `pointerup` is handled by the edge check.
  - While paused, no step runs and the last list is redrawn.
  - The UI layer is drawn before `flush` and the F005 capture point, under `normal` blend, with the previous blend restored.
- **9-slice:** the shrink rule, zero-area skips, `center: false` and inset validation (`RangeError`) match GAME_FORMAT. One call counts as one sprite.
- **Fan-out worker.** Exactly once under restart is shown by the replay in `rv5_migrate.py`.
  - A single in-process worker mutex prevents concurrent drains.
  - Chunks retry with linear backoff.
  - The cursor and the rows commit atomically.
  - Game delete and owner delete cascade the queue row away.
