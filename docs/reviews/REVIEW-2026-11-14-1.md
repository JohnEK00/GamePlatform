# Project review 2026-11-14 #1

Reviewer: `project-reviewer`. Scope: the whole repo at `1fc73fc` (v1 + v2). Uncommitted "F00x additions" planning sections in `docs/` and `docs/ROADMAP.md` / `docs/features/` were ignored because they are unimplemented plans.

## Summary

The codebase is in good shape. All checks pass: engine tests 69/69, UI tests 70/70, backend unit and integration tests (7 + 17 + 13), `cargo clippy --all-targets -D warnings` and `cargo fmt --check`. The sandbox boundary, the zip handling and the preview-token scoping are solid. The Dockerfile and CI workflow look correct when read, and the bundles the Studio's zip writer produces are accepted by a live backend.

The review found **1 high**, **6 medium** and **8 low** issues. The most serious is a reproduced data-loss race: two concurrent bundle replaces leave a game pointing at a version directory that no longer exists, and the previous version is already deleted. The game stays broken until someone uploads again. The medium issues are:
- anyone can inflate play counts without limit
- a Studio preview cannot run a project with more than one JS module
- the Studio code editor is a keyboard trap
- the container ignores SIGTERM
- game files are never cacheable
- several listing filters scan every published game

Repro setup: debug backend on port 18089 with a scratch `DATA_DIR`/DB and `RATE_LIMIT=off` (stopped afterwards). Scratch scripts are in the session scratchpad: `e2e/mkzips.mts` builds bundles with the real `packages/ui/src/studio/zip.ts`, and `eqp.py`/`eqp2.py` run `EXPLAIN QUERY PLAN` against the real migrations.

## Checked and fine

- **Checks:** engine 69 tests, UI 70 tests, backend 37 tests (all pass); clippy with `-D warnings` and `cargo fmt --check` are clean.
- **Studio publish, end to end:** zips built by the real `createZip` from all three `STUDIO_TEMPLATES` (blank, shooter, platformer), with achievements, were accepted by the live backend (`201` ×3). The UI-side validation (entry, dimensions, achievement rules) matches `bundle.rs`, apart from R11.
- **Sandbox boundary:**
  - `GAME_IFRAME_SANDBOX = "allow-scripts allow-pointer-lock"` (no `allow-same-origin`) is used by both GamePlayer and StudioPreview.
  - Both check `event.source === iframe.contentWindow`.
  - The player CSP includes `sandbox`, and game files carry `CSP: sandbox` and `nosniff`.
  - Preview tokens are scope- and gid-bound, and session tokens are rejected on `/play`.
  - The query string is never logged.
- **Bundle hardening:** zip-slip, absolute paths, symlinks, encrypted entries, extension allowlist, file-count limit and an actual-inflate cap (not just the declared size) are all handled; `game.json` is read with a bounded `take`.
- **Auth:**
  - argon2 hashing runs in `spawn_blocking`.
  - JWTs are scope-checked, and the user's existence is re-checked on every request.
  - The admin role comes only from `ADMIN_USERNAMES`.
  - `TRUST_PROXY` hop counting is correct and tested.
- **Migrations:** FKs and cascades are consistent, with `foreign_keys(true)` set on the pool and the composite FK on `user_achievements` cascading on achievement removal. Indices are used for comments, reports (status and target), favorites (user and game), user achievements, `play_events (game_id, day)`, and the new and popular listings.
- **Desktop (read only):**
  - Capabilities are least-privilege (event listen and unlisten only).
  - The folder reader rejects symlinks and junctions, canonicalises paths and enforces the upload limits.
  - All tauri.conf icon paths are tracked in git.
  - CI builds `apps/desktop/dist` before `cargo build`, which `frontendDist` needs.
- **CI workflow:** workspace commands match the `package.json` scripts, `rust-cache` points at the right workspaces, and the `--locked` builds have lockfiles.
- **Contrast:** muted text #8b91b0 is ≥4.59:1 on every surface, and primary button text is 7.57:1. A `prefers-reduced-motion` block is present, as is a skip link and `:focus-visible` rings across the app (except the editor, R4).
- **Empty, loading and error states** exist on every page. The gaps are R15.
